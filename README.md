# MTI6-GTADWIY-Cockpit

Daniel Richardson's sovereign cockpit — override control, emotional overlays, milestone logging, stealth trading flows, and spiritual presence.

## Quick start

Prerequisites
- Node.js 18+ (or your preferred LTS)
- npm or yarn

Install
```bash
npm install
# or
# yarn
```

Run (examples)
```bash
npm start       # run the app (if defined)
npm test        # run tests
npm run lint    # run linter
```

Project layout
- src/ — main JavaScript source
- public/ — static assets (if present)
- scripts/ — helper scripts

Contributing
- Open issues for bugs or feature requests.
- Fork -> branch -> PR for changes.
- Add tests for new behavior.
