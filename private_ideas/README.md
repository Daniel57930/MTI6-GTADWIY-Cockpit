# private_ideas — Private auto-saved messages

This folder is git-ignored and used to store your auto-saved messages and ideas privately. Files here will NOT be pushed to any public index or exposed; the folder is ignored by Git.

Structure:
- private_ideas/modules/<ModuleName>/ideas.md — module-scoped idea files

Do NOT share these files publicly. If you want to export an idea to the public repo, move it out of this folder or change .gitignore.
